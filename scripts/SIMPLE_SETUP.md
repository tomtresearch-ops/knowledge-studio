# Simple Knowledge Capture Setup (No Scriptable)

## Option 1: Manual Save (2 taps)
1. Screenshot → Share → Save to Files
2. Tap "Knowledge Capture" folder (favorite it so it appears at top)
3. Tap Save

Watcher automatically picks it up from `iCloud Drive/Knowledge Capture/`

## Option 2: Create iOS Shortcut (1 tap in share sheet)

### Create the Shortcut:
1. Open **Shortcuts** app on iPhone
2. Tap **+** to create new shortcut
3. Name it: **"Save to Knowledge Capture"**
4. Add actions:
   - **Get Latest Screenshots** (set to 1)
   - **Save File** → Choose `iCloud Drive/Knowledge Capture`
   - Turn OFF "Ask Where to Save"
5. Tap settings (sliders) → Enable **"Show in Share Sheet"**

### Use it:
- Screenshot → Share → Tap **"Save to Knowledge Capture"** (appears in share sheet)
- One tap, done!

## Favorite the Folder (for Option 1):
1. Files app → Browse → iCloud Drive
2. Long-press "Knowledge Capture" folder
3. Tap "Add to Favorites"
4. Now it appears at top when saving files
